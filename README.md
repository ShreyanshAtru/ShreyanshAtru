## Selected projects

### 01 · [Account Management Agent](https://github.com/ShreyanshAtru/Account-Management-Agent)

**Account and subscription support through modular Python tools.**

A prototype that brings account lookup, permission checks, and subscription-plan comparisons together behind an MCP server. The code separates account data, query parsing, permissions, and response formatting into focused modules.

- Eight MCP tools for account-support workflows.
- A demo with mock accounts and guidance for subscription changes.
- **Built with:** Python and FastMCP.

[Explore the project →](https://github.com/ShreyanshAtru/Account-Management-Agent)

---

### 02 · [Geolocation Address API](https://github.com/ShreyanshAtru/Geolocation-Address)

**Turn an address into latitude and longitude.**

A Django REST endpoint that accepts an address, validates the request, and delegates the location lookup to a separate service. A compact example of connecting an application API to an external service.

- Address input and output-format selection.
- Separate serializer, view, and service layers.
- **Built with:** Python, Django, and Django REST Framework.

[Explore the project →](https://github.com/ShreyanshAtru/Geolocation-Address)

---

### 03 · [Candidate Review App](https://github.com/ShreyanshAtru/Job_review_API)

**Browse candidate profiles and their application status.**

A Django prototype for reviewing candidate information. It includes candidate-list and detail pages, stored application statuses, and the beginnings of a review workflow.

- Candidate profiles and application-status displays.
- Server-rendered pages backed by Django models.
- **Built with:** Python and Django, with Django REST Framework components.

[Explore the project →](https://github.com/ShreyanshAtru/Job_review_API)
