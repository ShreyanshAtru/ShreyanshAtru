# Profile assets

- `header.webp`: custom header artwork, generated with the built-in imagegen tool and exported to WebP for a smaller page download.
- `focus.svg`: a self-contained vector graphic with gentle halo pulses. Text remains readable throughout; `prefers-reduced-motion` disables the animation.
- `badges/*.svg`: local vector badges for the technologies represented in the public projects.

All profile images are stored in this repository. They do not depend on an external badge or animation service. Each image has alternative text in the profile README.
